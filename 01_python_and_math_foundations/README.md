# 01 — Modern Python & Math Foundations for AI/ML

Welcome to the first milestone of your AI/ML journey! Machine Learning and Deep Learning frameworks (PyTorch, Scikit-Learn, TensorFlow) rely on clean, vector-oriented Python code.

---

## 🎯 Module Objectives

1. **Modern Idiomatic Python (`01_idiomatic_python.py`)**:
   - Master Python 3 type hints (`typing`), dataclasses, and pattern matching.
   - Use list/dictionary comprehensions and generator pipelines instead of verbose `for` loops.
   - Clean object-oriented design and functional paradigms.

2. **Vectorized Computing with NumPy (`02_numpy_vectorization.py`)**:
   - Understand why Python loops are 50x-100x slower than C-level vectorized arrays.
   - Master multidimensional arrays, shapes, slicing, and broadcasting rules.
   - Implement core ML mathematical functions from scratch (Mean Squared Error, Sigmoid, Binary Cross-Entropy).

3. **Data Wrangling & Feature Prep with Pandas (`03_pandas_data_wrangling.py`)**:
   - Data ingestion and structural inspection (`info()`, `describe()`).
   - Handling missing data (imputation vs dropping).
   - Categorical encoding (One-Hot Encoding, Label Encoding).
   - Aggregations and grouping for feature engineering.

---

## 🏃 Running the Scripts

```bash
# Run Modern Python Idioms
python 01_python_and_math_foundations/01_idiomatic_python.py

# Run NumPy Vectorization & Benchmarks
python 01_python_and_math_foundations/02_numpy_vectorization.py

# Run Pandas Feature Pipeline
python 01_python_and_math_foundations/03_pandas_data_wrangling.py
```
